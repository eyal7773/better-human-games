## 2. מודל התוכן

### 2.1 פריט (Entry)
כל פריט תוכן, מכל משחק, הוא רשומה אחת עם אותם שדות-חיפוש:

```ts
interface Entry<K extends Kind = Kind> {
  id: string;          // יציב לנצח (היסטוריה, אלבומים ושמירות נשענים עליו)
  kind: K;             // 'sentence' | 'dilemma' | 'scene' | 'bubble' | 'threat' | 'shout' | 'notif' | 'letter'
  with: Other;         // מול מי זה קורה (ראו 2.2) — השדה שקובע למי זה מתאים
  requires?: HouseholdTag[]; // נדיר: כשהמצב תלוי בשחקן עצמו ולא בצד השני (למשל 'single-parent')
  gender?: GenderTag;  // רק כשהמצב באמת ספציפי למגדר. נשמר הכלל הקיים: אף פעם לא כ-fallback
  topics: TopicTag[];  // על מה זה (בלגן, כסף, מסכים...)
  setting: Setting;    // 'home' | 'work' | 'road' | 'public' | 'online' — לשמות שלבים ולגיוון
  diff: 1 | 2 | 3 | 4 | 5; // קושי התוכן (לא המהירות) — מה כל ערך אומר מוגדר לכל kind
  heavy?: boolean;     // תוכן טעון רגשית (השפלה, בריאות, כסף שחסר) — ראו כללי מינון 3.3
  data: KindData[K];   // התוכן עצמו, בשלוש שפות
}
```

### 2.2 `with` — הצד השני (במקום לתייג קהל ידנית)
היום כותב התוכן צריך לזכור לתייג `parent-teen` על כל משפט מול מתבגר, וקל לשכוח. במקום זה, **כל פריט מצהיר מול מי הוא קורה, והקהל נגזר מטבלה אחת**:

| `with` | פנים (`face.ts`) | מתאים לבית עם |
|---|---|---|
| `young-child` | child | `parent-young-child` |
| `child` | child | `parent-school-age` |
| `teen` / `teen-girl` | teen / teenGirl | `parent-teen` |
| `kids` (כמה ילדים, ריב אחים) | child | כל אחד מתגיות הילדים |
| `partner` / `partner-f` / `partner-m` | partner (+ חדשות) | `partner` |
| `ageing-parent` | grandma (+ grandpa) | `adult-child` |
| `grandchild` | child | `grandparent` |
| `family` (משפחה מורחבת, חמות, אחים בוגרים) | חדשות | **כולם** |
| `boss` / `coworker` | חדשות | **כולם** |
| `friend` / `neighbor` / `roommate` | חדשות | **כולם** |
| `stranger` (נהג, תור, שירות לקוחות) | חדשות | **כולם** |
| `none` (מצב בלי אדם: פקק, טלפון על 5%) | — | **כולם** |

כך מי שבחר "בלי ילדים" מקבל בן/בת זוג, עבודה, חברים, שכנים, משפחה, כביש, ותוכן "כללי". **פריט מול ילד לעולם לא יגיע אליו.**

### 2.3 התאמה דקדוקית לשחקן
בטקסט העברי והערבי, צורות שתלויות במין השחקן נכתבות כ-`{מרגיש|מרגישה}` ונפתרות לפי צורת הפנייה בפרופיל. ב-`x` מקבלים את צורת הלוכסן ("מרגיש/ה"), כמו היום. זו הכללה של `heSelf` לכל הטקסטים בספרייה. המין של **הצד השני** קבוע בפריט (`teen` מול `teen-girl`, `partner-f` מול `partner-m`), כך שהטקסט נכתב מדויק ולא בלוכסנים.

### 2.4 איפה התוכן יושב
- `src/shared/library/` — הטיפוסים, הטבלה של 2.2, `query`, ההיסטוריה, והבדיקות.
- התוכן עצמו נשאר ליד המשחק שלו (`src/<game>/content/*.ts`), אבל כתוב כ-`Entry[]` ונרשם בספרייה. כל פריט מחזיק את שלוש השפות יחד (כמו היום במילים באוויר), כדי שאי אפשר יהיה להוסיף משפט בשפה אחת ולשכוח את השאר. `translations.test.ts` הקיים מורחב לכל הספרייה.
- כל משחק טוען רק את ה-`kind`-ים שלו, כך שגודל העמוד לא גדל בגלל תוכן של משחקים אחרים.

## 3. השאילתה (`query`)

```ts
query(kind, {
  count,                 // כמה פריטים
  diff?: [min, max],     // טווח קושי לשלב
  game,                  // לרישום ההיסטוריה
  profile?, seen?, rng?, // ברירות מחדל: הפרופיל, ההיסטוריה והאקראיות האמיתיים; בבדיקות מזריקים
}): Entry[]
```

### 3.1 מי בכלל כשיר
1. **מגדר:** הכלל הקיים של `allowed`, בלי שינוי.
2. **בית:** אם הפרופיל הושלם ויש בו תגיות בית, פריט כשיר רק אם `with` שלו (או `requires`) מתאים לבית. **אין נפילה לתוכן שלא מתאים**, בניגוד להתנהגות של נקודת רתיחה היום. אם אין מספיק, מקבלים פריטים מתאימים שכבר נראו (3.2).
3. **בלי פרופיל:** כל התוכן כשיר (כמו היום), אבל בשלבים 1–2 מעדיפים פריטים "לכולם" (`partner`, `family`, `boss`, `stranger`, `none`), כי הם רלוונטיים לרוב האנשים. כך השחקן לא נתקל מיד במצב שלא שלו (ראו 10.1).

### 3.2 סדר העדפה
1. כשירים ו**לא נראו מעולם**.
2. כשירים שנראו **הכי מזמן**.

בתוך כל שכבה הסדר אקראי וממושקל: נושא מקפיץ ×2 (כמו היום).

### 3.3 כללי גיוון ומינון (חלים על התוצאה)
- **לא אותו צד שני פעמיים ברצף** כשיש חלופה (לא שלושה משפטים מול המתבגר ברצף).
- **נושאים מקפיצים: עד מחצית מהשלב.** המשקל ×2 נשאר, אבל לא יותר מזה, כדי שהשלב לא יהפוך לרצף של הדבר שהכי קשה לי.
- **תוכן `heavy`:** לא בשלב הראשון של משחק, לא יותר מפריט אחד בשלב, ולא ברצף.
- **התחלה רכה:** בשלב 1 של כל משחק, `diff` 1 בלבד.

### 3.4 היסטוריה
`bhg.library.v1`: `{ seen: Record<id, number> }`, כאשר המספר הוא מונה משחקים גלובלי (לא תאריך), כך שגם "הכי מזמן" עובד בלי שעון. ההיסטוריה משותפת לכל המשחקים, כי אותו מצב יכול להופיע ביותר ממשחק אחד (ראו 6). נשמרים לכל היותר 2,000 פריטים, והישנים נזרקים ראשונים.

### 3.5 בדיקת כיסוי (חובה, רצה ב-CI)
`library.coverage.test.ts` מגדיר **פרסונות**, ולכל אחת מוודא שכל שלב בכל משחק מתמלא **בלי חזרה בתוך מעבר שלם על המשחק** ובלי שום פריט שלא מתאים לה:

| פרסונה | בית |
|---|---|
| הורה לפעוטות | `parent-young-child`, `partner` |
| הורה למתבגר | `parent-teen`, `partner` |
| הורה יחידני | `single-parent`, `parent-school-age` |
| זוג בלי ילדים | `partner`, `no-kids` |
| גר/ה לבד | `no-kids` |
| מטפל/ת בהורה | `adult-child`, `no-kids` |
| סבא/סבתא | `grandparent`, `partner` |
| בלי פרופיל | — |

כך "יש מעט תוכן" הופך ממשהו שמרגישים בשימוש לבדיקה שנכשלת. כמות התוכן בסעיף 6 נגזרת מהבדיקה הזו.

### 3.6 כלי לכותבי תוכן
`?debug=content` בכל משחק: בוחרים פרסונה ורואים מה כל שלב היה שולף, וכמה פריטים כשירים יש לכל `kind`. זה מאפשר לראות חורים לפני שכותבים.

## 4. שלבים: מכניקה, לא תוכן

היום שלב הוא חבילת תוכן ("בדרך לבית הספר" = משפטים על הסעה). במודל החדש **שלב מגדיר רק מה חדש בו ומה הקושי**, והתוכן נשלף:

```ts
interface LevelDef {
  id: string;          // יציב ('l1'…), לא תלוי בתוכן
  diff: [min, max];
  count: number;
  twist?: string;      // החידוש של השלב (ראו 5)
  // + הכוונון של המשחק (מהירות, גלים...)
}
```

**שמות שלבים** לא מבטיחים תוכן שאולי לא יגיע ("בדרך לבית הספר" אצל מי שאין לו ילדים). השם מתאר את החידוש או את השעה ביום ("ערב רגוע", "מילים שנשמעות נחמדות", "יום ארוך"), או נגזר מה-`setting` שרוב התוכן שנשלף שייך אליו.

**שמירות:** מזהי השלבים של מילים באוויר ושל המבצר כבר כלליים, ונשארים. בצל על הקיר מזהה השלב הוא היום מזהה הסצנה: מבצעים הסבה חד-פעמית (`done` ו-`stars` של `juice` → `l1` וכן הלאה, לפי הסדר הקיים), כדי שאף כוכב לא ילך לאיבוד. האלבום של צל על הקיר נשאר לפי מזהה סצנה.

## 5. משחק-משחק

### 5.1 מילים באוויר 💬
- **תוכן:** 22 → **~120 משפטים**. כל משפט הוא `Entry<'sentence'>`, וה-`who` הקיים עובר ל-`with`.
- **`diff`** (מה שהיום הוא `lvl`): 1 "תמיד/אף פעם", 2 רגשות שאסור לחתוך, 3 תוויות ועלבונות, 4 "תודה" שאינה "אתה תמיד", 5 ויכוח ארוך.
- **שלבים: 5 → 10 + אינסופי.** כל שלב מוסיף מהירות **וגם** חידוש, כדי שלא יהיה "אותו דבר, רק מהר":

| שלב | diff | חידוש |
|---|---|---|
| 1 | 1 | הכרות (כולל הנשימה המודרכת) |
| 2 | 1–2 | מילים ירוקות: רגש שאסור לחתוך |
| 3 | 1–3 | תוויות ("עצלן", "ילד רע") |
| 4 | 2–3 | מילים נייטרליות שנראות מאיימות |
| 5 | 2–4 | "תודה" ו"אני אוהב/ת" שעפים ליד "אתה תמיד" |
| 6 | 3–4 | שתי מילים פוגעות צמודות |
| 7 | 3–5 | **עוקץ מוסווה**: "כל הכבוד, שוב איחרת" (מילה ניטרלית בצבע, פוגעת בתוכן) |
| 8 | 4–5 | משפט ארוך יותר |
| 9 | 4–5 | שני משפטים ברצף בלי הפסקה |
| 10 | 5 | "הוויכוח הגדול" |

- **הפנים והתגובות** לפי `with`: פנים חדשות למבוגרים (`boss`, `friend`, `neighbor` ועוד), והתגובות (`REPLY`) מתאימות לצד השני ("בסדר, אמא" לא נאמר לבוס).
- **אלבום חדש: "משפטים שתיקנתי"** — אוסף הגרסאות הכנות שנחתו. המונה סופר **רק משפטים שכשירים לבית שלכם**, כך ש-100% אפשרי לכל שחקן.

### 5.2 נקודת רתיחה 😤
- הדילמות עוברות לספרייה עם **אותם מזהים** (ההיסטוריה ב-`save.ts` נשמרת). `pickDilemmas` מוחלף ב-`query`, ומבוטלת הנפילה לדילמות שלא מתאימות לבית.
- 45 → **~90 דילמות**, בעיקר כדי למלא את הפרסונות שהיום כמעט ריקות: עבודה, חברים, שכנים, שותפים לדירה, הורה מבוגר, זוג בלי ילדים.
- **צעקות והתראות** (`shout`, `notif`) הופכות לפריטים עם `with`: "אמאאא!" רק להורים, ולמי שאין לו ילדים: הודעה מהקבוצה של העבודה, שכן שקודח, שותף ששואל איפה המטען.
- **משימות הבית** (צעצועים, כריך, גרביים): **שלב מאוחר, אופציונלי.** אלה מכניקות, והחלפת "צעצועים" ב"ניירת" היא עבודת ציור. נכנס רק אם תאשרו (11).

### 5.3 צל על הקיר 🔦
- הסצנות הופכות ל-`Entry<'scene'>`. 8 → **~24 סצנות** (לכל צד שני לפחות 2: למשל לבוס "מייל בעשר בלילה", לשכן "חנה לכם בחניה", לחבר "ביטל ברגע האחרון", לזוגיות "איחור לארוחה").
- **שלבים: 8 → 12.** השלב קובע את הדרישה המכנית, והסצנה נשלפת לפיה: בשלבים 4, 8 ו-11 נשלפת סצנה שבה נשאר משהו אמיתי (`right: 'boundary'`), כמו היום. בשאר — סצנה שבה הצל מתכווץ לגמרי.
- "הצל שלי" לא משתנה.

### 5.4 המבצר 🏰
- בועות ואיומים הופכים לפריטים (`bubble`, `threat`) עם `with`. "שכחו את התיק" רק להורים, ו"מישהו דוחף את הילד שלכם" רק לבית עם ילדים. 14 → **~40 בועות**, 7 → **~20 איומים**.
- **שלבים: 5 → 8 + אינסופי.** חידושים: איום מוסווה (קיים), שני איומים יחד, בועה שנראית כמו איום, וגל שבו כל איום הוא בעצם בועה (המגן מיותר).

### 5.5 איי השקט — מכתבים בבקבוקים
המכתבים הופכים ל-`Entry<'letter'>`. טיפ על "שיעורי בית" רק להורים. עדיפות נמוכה, בסוף.

### 5.6 לא משתנה
"תפוס אותי" (סיפור קבוע), "תפוס אותי פשוט", ו"אני כועס/ת עכשיו" (אין בהם מאגר מצבים).

## 8. "הבית שלי"

אין שאלות חדשות חובה. יש **שני אריחים חדשים** במסך "מי גר איתכם?", כדי שגם מי שגר לבד או עם שותפים יוכל לתאר את הבית שלו:
- 🏠 **"גר/ה לבד"** (`lives-alone`)
- 🛋️ **"שותפים לדירה"** (`roommates`)

נושאים מקפיצים חדשים: **"עבודה"**, **"כביש"**, **"שכנים"** (מתווספים ל-12 הקיימים).

אחרי שינוי בבית, ההיסטוריה (`seen`) לא מתאפסת, אבל תוכן שהפך ללא כשיר פשוט מפסיק להופיע.
